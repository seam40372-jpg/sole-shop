# Sole Shop

A responsive, fully client-side shoe store: sneakers, boots and everyday footwear.

## Features
- 12 styles with per-size stock, sale pricing and ratings
- Category filters plus live name search
- Per-size add to bag, quantity controls, persistent bag (localStorage)
- Subtotal, shipping threshold and total calculation
- Size conversion table, form validation, toasts, keyboard escape to close the bag
- Responsive down to small phones

## Going live
Checkout and inventory are demo-only in the browser. Real orders need a backend, database and payment provider.
